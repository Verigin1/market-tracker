SpaceX创纪录IPO上市，马斯克成全球首位万亿美元富豪

SpaceX于6月12日在纳斯达克正式挂牌，发行价135美元/股，开盘涨11%至150美元，收盘报160.95美元（+19.22%），市值突破2.1万亿美元。机构认购需求超2500亿美元，约三分之一机构未获配。马斯克净资产突破1.1万亿美元，成为全球首位万亿美元富豪。

来源：财联社 / 证券时报 / Nasdaq

美伊和平协议接近签署，地缘风险降温

巴基斯坦总理夏巴兹表示，美伊已就和平协议最终文本达成一致。Polymarket显示6月底前达成协议概率从不足三成飙升至43%。美伊和谈顺利令油价大幅回落（WTI跌至84美元附近），通胀预期降温推动全球股市普涨，风险偏好回升。

来源：路透社 / 华尔街见闻 / Bloomberg

黄金单日暴涨3%，收复4200美元关口

受美伊和谈利好和美元走弱提振，COMEX黄金期货大涨3.06%至4239.90美元/盎司，伦敦现货金收报4218美元。本周从4024美元低点反弹约5%，但YTD仍基本持平（从5598美元高点回撤超20%）。央行购金和地缘支撑逻辑暂未改变。

来源：金投网 / 凤凰网 / 世界黄金协会

央行6000亿放水+指数换血，A股放量站上4000点

央行宣布6月15日开展6000亿元6个月买断式逆回购（相当于降准0.5%量级），叠加沪深300/上证50/科创50指数样本调整引近千亿被动资金。沪指收涨1.12%至4031.51点，两市成交3.21万亿放量6629亿，有色/券商/军工领涨，半导体/AI高位回落。

来源：每日经济新闻 / 新浪财经 / 陆家嘴财经早餐
中性 影响: 黄金 / 美债

欧洲央行三年来首加息，全球央行转向收紧

欧央行6月11日宣布加息25bp至2.25%，为三年来首次加息。日本央行预计6月16日再次加息。英国央行也暗示年内加息。SMBC日兴统计显示4-5月加息央行数量已超降息央行。地缘引发的通胀压力正推动全球央行政策转向。

来源：日经中文网 / 新浪财经
