8月19日美股收盘 · 市场热点
利空 影响: A股/科技股/半导体/资金流向/市场情绪

🔻 A股"黑色星期三"：沪指-2.40%失守3900，科创50-6.89%，超5000股下跌百股跌停

上证指数-2.40%报3,894.42失守3900，深成指-5.01%，创业板-6.26%，科创50-6.89%。全市场超5,000只个股下跌，115只跌停，成交2.51万亿放量1,100亿，属典型恐慌性放量暴跌。电子板块净流出582亿（半导体-364亿、通信-258亿），资金涌入银行+1.78%、煤炭逆势上涨。三重压力共振：①隔夜30Y美债5.32%创2007年来新高→全球科技股估值承压；②科技赛道拥挤度过高+获利盘集中兑现；③高位人气股批量跌停（爱丽家居/一鸣食品）催化恐慌情绪。宇树科技上市首日+460%成唯一亮点。中信建投认为短期超跌明显，8月行情大概率以修复为主。

来源：东方财富 / 新华社 / 粤开证券 / 华夏时报 · 2026-08-19
利好 影响: 美股/CPI/降息预期/国债收益率/科技股

📈 美股终结三连跌：S&P +0.21%报7,708，7月CPI 2.9%低于预期，降息预期升温

S&P 500 +0.21%报7,707.98，纳斯达克+0.16%报26,331.09，道指+0.22%报53,463.05，终结三日连跌。核心催化：7月CPI同比2.9%（预期3.2%），为2021年3月以来最低，市场押注9月降息25bp概率升至75%。Moderna+177%（与默沙德mRNA癌症疫苗Phase 3数据积极），默沙德+13%。Target+5%（Q2同店销售+3.8%超预期）。但存储/光通信板块继续承压（Sandisk-9%）。Fed纪要显示若通胀不降支持加息，但CPI数据明显缓解了市场焦虑。VIX降至14.3。

来源：Nasdaq.com / 中财网 / Motley Fool / MarketInsiders · 2026-08-19
利好 影响: 美债/收益率/流动性/财政部政策/长端利率

🏛️ 美国财政部意外宣布扩大国债回购规模：10Y收益率盘后跌至4.55%，长端压力缓解

美东时间周三，美国财政部宣布大幅扩大长期国债回购规模——10-20年期和20-30年期流动性支持回购操作规模从每次20亿美元翻倍至至少40亿美元，9月9日生效。消息公布后10Y收益率从4.71%→4.545%（-17bp），2Y→4.164%（-3bp），30Y→5.058%（-2bp）。法国外贸银行首席策略师John Briggs称"此举时机具有重要意义"——此前30Y一度升至5.323%创19年新高。分析人士指出财政部意外扩大回购旨在稳定长端流动性，缓解此前因AI融资+战争通胀+债务突破$40万亿带来的抛压。

来源：凤凰网 / Morningstar / SlickCharts / Fed H.15 / gmt8press · 2026-08-19
利好 影响: 黄金/CPI/避险/央行购金/美元/通胀

🥇 黄金飙升至$4,519：CPI低于预期+财政部回购扩盘，突破$4,500大关

现货黄金大涨4.3%至~$4,519/盎司，突破$4,500心理关口。双催化驱动：①7月CPI 2.9%低于预期→降息预期升温→实际收益率下行→黄金估值修复；②财政部扩大国债回购→长端收益率急跌→持有黄金机会成本骤降。美元继续走弱（DXY在99附近）+地缘避险（霍尔木兹海峡僵局未解）构成底部支撑。近一月黄金从$4,049→$4,519（+11.6%），年内首次转正YTD约+1%。年同比+33%。本周关注：Jackson Hole鲍威尔演讲——对通胀容忍度的表态将决定黄金短期方向。

来源：每经 / Fortune / jinjia.zzcha.com / 凤凰财经 · 2026-08-19
利好 影响: 比特币/加密/鲸鱼/CPI/ETF/DeFi

₿ 比特币飙涨7.2%至$69,268盘中触$70,000：鲸鱼60天增持$29亿+CPI催化

比特币大涨7.2%至$69,268（UTC+8日收盘），盘中最高触及$70,000整数关口——为数周以来首次。核心催化：①CPI 2.9%低于预期→降息预期升温→风险资产全线反弹；②Bloomberg报道鲸鱼60天内增持$29亿BTC，结束此前持续抛售周期；③BTC ETF连续多日净流入。但Fear & Greed指数仅46（恐惧区间），市场情绪尚未跟上价格。技术面：小时RSI 85+、日线RSI 71+进入超买区间，但仍低于200日EMA（$71,676），日线趋势尚未确认反转。Fundstrat认为BTC overdue for 30%+ move。

来源：AASTICKS / CoinDesk / Bloomberg / The Cryptonomist · 2026-08-19
关注 影响: 港股/银行/科技/AI/中概/芯片

🇭🇰 恒指微涨+0.09%报25,495：银行石油走强，AI产业链港股承压回调

恒生指数+0.09%报25,495.07，恒生科技指数-1.21%报4,682.05。结构分化持续：银行股受息差改善预期上涨（中信银行+2.2%，农业银行+2.1%）；中国石油+1.6%受益地缘溢价。但AI/光通信/存储芯片受隔夜费半暴跌拖累大幅回调——华虹宏力-11.8%，剑桥科技-11.7%，中际旭创-10.1%。小米+4.8%（前日超跌反弹），新东方+4.2%。整体看港股在A股暴跌+美股反弹之间走势温和，等待方向选择。
